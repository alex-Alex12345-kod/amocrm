## Блокер
После выбора тестового аккаунта в официальном окне amoCRM создание внешней интеграции возвращает Code 403. На одной промежуточной попытке возвращено An unknown error occurred. Повтор после исправления и переноса логотипа в GitHub также дал Code 403.

При последней проверке хранилища ключей OAuth в pending-записях не было client_id/client_secret; access_token не получен. Запросы обычного HTTP-клиента к стенду из исполнительной среды возвращают 403/1010, поэтому их нельзя использовать как доказательство общедоступности приемника для других серверных клиентов. Точная причина отказа amoCRM не установлена.

## Не подтверждено
- Чтение реальных данных amoCRM через внешнюю интеграцию.
- Доступность серверного объединения существующих карточек внешней интеграции.
- Сохранение переписок, звонков, задач, примечаний и связей при слиянии.

Механизм реальной автосклейки пока не реализован. Повторные регистрации и смена провайдеров не доказали доступность нужного метода API. Следующий этап должен диагностировать отказ OAuth на уровне запросов и ответов, а затем отдельно проверить механизм объединения.

Секреты, временные токены Cloudflare и ссылка claim исключены из репозитория и отчетов.
